
# 3. Requirements Gathering

## 3.1 Stakeholder Analysis

The main stakeholders of the NutriVision application are:

- **Users:** People who want to explore food information, manage their meals, and receive meal suggestions.
- **Development Team:** Responsible for designing, developing, and testing the mobile application using Flutter.
- **DEPI Evaluators:** Responsible for evaluating the project's functionality, design, and overall implementation.

## 3.2 User Stories & Use Cases

The following user stories describe the main interactions with the NutriVision application:

- **Explore Food Information:** As a user, I want to view food information to better understand the meals I eat.
- **Manage Meals:** As a user, I want to add and organize meals to keep track of my food choices.
- **Save Favorite Meals:** As a user, I want to save my favorite meals so that I can access them easily.
- **Receive Meal Suggestions:** As a user, I want to receive suitable meal suggestions based on available food information.
- **Browse Saved Meals:** As a user, I want to view my saved meals whenever I need them.

## 3.3 Functional Requirements

The NutriVision application will provide the following functionalities:

- **Food Information:** Display relevant information about different foods and meals.
- **Meal Management:** Allow users to add, view, and organize meal information.
- **Favorite Meals:** Enable users to save and access their favorite meals.
- **Smart Meal Suggestions:** Provide meal suggestions based on food information and user preferences.
- **User-Friendly Navigation:** Allow users to move easily between the application's screens.
- **Data Management:** Support storing and retrieving meal information through a suitable data source.

## 3.4 Non-Functional Requirements

The application should meet the following quality requirements:

- **Usability:** Provide a clear, simple, and user-friendly interface.
- **Performance:** Ensure smooth navigation and reasonable response times.
- **Security:** Protect user information and handle stored data appropriately.
- **Reliability:** Ensure the application works consistently during normal use.
- **Maintainability:** Organize the code into reusable widgets and structured files to simplify future updates.
- **Compatibility:** Support Android devices compatible with the selected Flutter configuration.

## 3.5 Smart Food Features

NutriVision aims to provide a smarter food experience by presenting useful food information and personalized meal suggestions. These features will help users explore meal options and make more informed food choices through the mobile application.
