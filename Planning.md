# 1. Project Planning & Management

## 1.1 Project Proposal

### NutriVision: AI-Driven Dietary Health Assistant

NutriVision is a mobile application designed to help users manage their dietary habits through AI-powered meal analysis, nutritional information, and personalized food recommendations. The application allows users to record their meals, explore healthier alternatives, and track their dietary history through a user-friendly interface.

The project aims to promote healthier eating habits by making nutritional information more accessible and helping users make informed food choices.

## 1.2 Project Plan

The project will be developed in several phases, including planning, requirements gathering, system analysis and design, implementation, testing, and final presentation.

### Project Timeline

- **Project Planning & Management:** October 16, 2026
- **Literature Review:** October 16, 2026
- **Requirements Gathering:** October 16, 2026
- **System Analysis & Design:** November 6, 2026
- **Implementation (Source Code & Execution):** November 30, 2026
- **Final Presentation, Testing & Reports:** December 4, 2026

### Main Deliverables

- Project proposal and planning documents.
- Requirements specification and system design diagrams.
- UI/UX designs and Flutter application screens.
- Working mobile application with AI-powered dietary assistance.
- Integration with external APIs using Dio and meal-history storage using Firebase Cloud Firestore.
- Testing reports, technical documentation, and a GitHub repository.

## 1.3 Task Assignment & Roles

Team members will share responsibilities according to their skills and assigned tasks. The main responsibilities include:

- **Project Management:** Organizing tasks, monitoring progress, and coordinating team activities.
- **UI/UX Design:** Designing wireframes, layouts, and a consistent user interface.
- **Flutter Development:** Implementing application screens, navigation, and state management.
- **AI Integration:** Preparing prompts and integrating AI-generated nutritional information and food recommendations.
- **Backend & Data Management:** Handling API communication, user data, and meal-history storage using Firebase.
- **Testing & Documentation:** Testing application functionality, fixing bugs, and preparing project reports.

Specific tasks will be assigned to team members based on the team's final structure and individual responsibilities.

## 1.4 Risk Assessment & Mitigation Plan

- **Inaccurate AI-Generated Recommendations:** Use carefully designed prompts, validate outputs where possible, and clearly communicate that AI suggestions are informational rather than medical advice.
- **External API Failures:** Handle network errors, loading states, and empty responses using Dio and appropriate error-handling mechanisms.
- **Data Privacy & Security:** Apply suitable Firebase security rules and avoid exposing sensitive information or API keys in the source code.
- **Development Delays:** Divide the work into smaller tasks, set internal deadlines, and review progress regularly.
- **Application Performance Issues:** Optimize UI rendering, manage application state appropriately, and test the application on different screen sizes.

## 1.5 KPIs (Key Performance Indicators)

The following indicators will be used to evaluate the project's success:

- **Functional Completeness:** Percentage of planned features successfully implemented.
- **API Reliability:** Percentage of API requests completed successfully under normal network conditions.
- **Response Time:** Time required to retrieve nutritional information or generate AI-powered recommendations.
- **Data Accuracy:** Consistency of stored meal records and correctness of nutritional calculations when applicable.
- **Usability:** Ease of navigation and completion of common tasks by test users.
- **Test Coverage:** Number of critical application features tested and verified.
- **Project Completion:** Completion of planned deliverables before the final submission deadline.
